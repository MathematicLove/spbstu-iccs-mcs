## Данные

Файл `creditcard_2023.csv` содержит данные о транзакциях кредитных карт.

## Задание

Фильтруем данные, работаем только с транзакциями с Amount >= 9000.00, группируем данные 
по интервалам признака V1 в 0.1 единицы, выводим в файл 50 групп с наибольшим мат. 
ожиданием признака V11 среди групп с наибольшим числом отрицательных значений признака V7 
по убыванию общей суммы Amount в группе.

## Сборка

Проект обязательно должен быть расположен в общей директории для всех узлов,
например, в `/mnt/share/supercomputers/build`. 
Перед запуском указать актуальный путь в `run.slurm`.

Подключение к серверу:
```sh
ssh -p43111 ayzek@127.0.0.1
```

Файл данных должен быть доступен на всех узлах через `/mnt/share/creditcard_2023.csv`.

### Сборка проекта

```sh
make clean
make
```

### Запуск

```sh
make run
```

Или напрямую через sbatch:
```sh
sbatch run.slurm
```

### Параметры командной строки

Программа поддерживает параметр для указания количества выводимых групп:

```sh
./bitcoin_app -n 100    # Вывести топ 100 групп (по умолчанию 50)
./bitcoin_app --top-n 25  # Вывести топ 25 групп
./bitcoin_app -h        # Показать справку
```

**Примечание:** При запуске через SLURM параметры командной строки нужно передавать через переменную окружения или изменить `run.slurm`.

### Валидация данных

Программа автоматически проверяет:
- Доступность файла данных на всех узлах
- Наличие валидных записей после фильтрации (Amount >= 9000.00)
- Корректность формата данных

При обнаружении ошибок программа выведет подробное сообщение и завершится с кодом ошибки.

Обязательно должны быть запущены все 4 нода (ayzekCPU1, ayzekCPU2, ayzekGPU1, ayzekGPU2). 
Результат будет в `~/result.csv`.
